ℹ️ Wie funktioniert das?
Übersicht über den automatischen Voice-Creator-Flow
1. Erstell-Kanal: Ein spezieller Voice-Kanal (➕ Kanal erstellen) wird in der gewählten Kategorie erstellt.

2. Kanalerstellen: Wenn ein Mitglied diesem Kanal beitritt, wird automatisch ein eigener Voice-Kanal erstellt und das Mitglied dorthin verschoben.

3. Panel: Im neuen Kanal erscheint ein Steuerungs-Panel mit dem der Kanalbesitzer den Kanal auf Privat stellen, User kicken, ein Limit setzen oder den Kanal löschen kann.

4. Privat-Modus: Bei privatem Kanal erscheint ein Warteraum. Anfragen werden über Annehmen/Ablehnen-Buttons verwaltet. Eine temporäre Zugangs-Rolle wird automatisch erstellt und nach Kanalende gelöscht.

5. Auto-Cleanup: Leere Kanäle werden nach dem eingestellten Timeout automatisch gelöscht.
